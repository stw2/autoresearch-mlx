## Assertion

On the current shallow anchor with `FINAL_LR_FRAC=0.02`, lowering warmup below `0.02` improved the local rerun ordering: `WARMUP_RATIO=0.015` finished best and `0.01` was next. However, none of the four runs reproduced the inherited `1.407875` anchor, so this only supports a low-confidence local preference for `0.01-0.015` over a rerun at `0.02`, not a confirmed new default.

## Falsification

The planned disproof case raised warmup to `0.04`. If the local optimum were truly below `0.02`, this run should have fallen behind the lower-side probes, and it did: `0.04` finished worse than both `0.01` and `0.015`. But it was only `0.000123 bpb` better than the same-session `0.02` control rerun, which is inside the repo's stated noise band. That means the falsification only partially tightened the claim: the lower values look locally better in this batch, but the absolute ordering around the inherited anchor remains noisy.

## Implications

Future warmup work should treat `0.01-0.015` as the most promising neighborhood under the `FINAL_LR_FRAC=0.02` schedule, but only in a reproduction-focused sense. The next useful follow-up is repeated reruns of `0.015` versus the inherited `0.02` anchor code, not a broader sweep away from this region or a premature anchor update.
