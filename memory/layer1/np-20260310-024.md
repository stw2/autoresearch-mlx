## Assertion

On the current shallow anchor, lowering `SCALAR_LR` below `0.5` did not improve `val_bpb`, and increasing it to `1.0` also hurt. Across the three non-control probes, the inherited `SCALAR_LR=0.5` anchor remained better than `1.0`, `0.25`, and `0.125`, so this axis does not look promising at the current settings.

## Falsification

The falsification test was the high-side run at `SCALAR_LR=1.0`. If the current scalar learning rate were too low, this run should have improved or at least matched the anchor; instead it regressed to `1.415744`, which is worse than both the incoming anchor and the same-session control rerun.

## Implications

This is a useful negative result: the current scalar-path optimizer settings are not the next obvious source of gains on the shallow anchor. Follow-up work should spend time on other untouched axes rather than refining `SCALAR_LR` more tightly around `0.5`.
