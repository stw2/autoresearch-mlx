## Assertion

On the current shallow anchor with `WARMUP_RATIO=0.02` and `FINAL_LR_FRAC=0.02`, increasing `UNEMBEDDING_LR` above `0.004` did not produce a new best run. The best higher setting tested was `0.005`, and `0.006` was also better than the same-session `0.004` control rerun, but both still missed the inherited anchor at `1.407875`; `0.008` was worse again.

## Falsification

The decisive disproof attempt pushed `UNEMBEDDING_LR` up to `0.008`. If the current anchor simply needed a materially larger unembedding step size, this run should have overtaken the inherited `0.004` result. Instead it regressed to `1.412482`, worse than both the inherited anchor and the interior probes. The smaller increases to `0.005` and `0.006` did recover part of that loss relative to the same-session control, but neither crossed the anchor, so the broader "raise `UNEMBEDDING_LR` to improve the anchor" hypothesis is not supported.

## Implications

Future sessions should keep `UNEMBEDDING_LR=0.004` as the working shallow-anchor default. If this axis is revisited, it should be framed either as a reproducibility check of `0.004` versus `0.005` under multiple reruns or as part of a larger architectural or schedule change, not as evidence that simply increasing `UNEMBEDDING_LR` is a reliable win on the current anchor.
