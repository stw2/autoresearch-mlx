## Assertion

For the current depth-2 shallow anchor, the existing last-layer-only value embedding placement remains the best tested configuration. Removing value embeddings, moving them to the first layer, or enabling them in both layers all caused large regressions, so there is no evidence that VE simplification or broader VE coverage helps this setup.

- Peak memory stayed effectively flat at `18.6 GB`; parameter count ranged from `2.5M` with no VE to `4.6M` with VE in both layers

## Falsification

The main disproof attempt enabled value embeddings in both layers. If the incumbent design were merely underusing VE capacity, that broader placement should have improved or at least matched the anchor. Instead it regressed sharply to `1.473791`, worse by `0.055765 bpb`. The two supporting probes then showed that both removing VE entirely and moving the single VE layer earlier were even worse, so the surviving conclusion is that the current late-only placement is the best tested option for this shallow model.

## Implications

Future sessions should leave VE placement unchanged on the current shallow anchor and spend search budget on other axes. If VE is revisited later, it should likely be in the context of a different depth or width regime rather than further tuning around this depth-2 anchor.
