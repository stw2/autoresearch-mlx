## Assertion

At the current shallow anchor, changing the learning-rate decay schedule away from the incumbent `WARMDOWN_RATIO=0.5` did not improve `val_bpb`. Both flatter schedules (`0.25` and `0.0`) regressed, and the more aggressive `0.75` decay regressed as well, so the default 50% warmdown remains the best tested local setting.

## Falsification

The session hypothesis predicted that flatter decay would outperform the incumbent schedule, so the strongest disproof was the constant-LR run at `WARMDOWN_RATIO=0.0`. Instead of improving, it failed hard at `1.526014`, trailing the anchor by `0.094750 bpb`. The milder flatter schedule at `0.25` also regressed to `1.441871`, so the positive hypothesis was already refuted before considering the steeper-decay negative control at `0.75`.

## Implications

For the current depth-2, 128-d shallow regime, the existing 50% warmdown looks materially better than either flatter or steeper tested schedules. Follow-up work should treat the LR schedule as provisionally stable and spend budget on other training dynamics unless a broader optimizer change justifies reopening it.
