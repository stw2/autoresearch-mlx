## Falsification

The designed falsification run raised `EMBEDDING_LR` to `0.8`, which should have lost if the original "lower is better" hypothesis were correct. Instead it improved to `1.416658`, outperforming the incoming anchor by `0.001695 bpb`. The direct target test at `0.4` then failed decisively, and the upper-bound test at `1.0` also regressed, leaving the original hypothesis refuted and pointing to a local optimum near `0.8`.

## Implications

Future optimizer work on the shallow anchor should keep `EMBEDDING_LR` above the original `0.6` default, with the next reproduction-focused sweep centered around `0.7-0.9`. Since the best gain here comes from a single non-reproduced run, it should be treated as a promising but still low-confidence improvement rather than a settled default.
