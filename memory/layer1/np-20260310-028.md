## Falsification

The direct disproof path moved both knobs in the opposite direction, to `WARMUP_RATIO=0.04` and `UNEMBEDDING_LR=0.008`. If the session story were simply wrong and the model preferred larger values on both axes, that branch should have overtaken the anchor or at least clearly outperformed the lower-side combo. It did neither: `val_bpb=1.410595` was still `0.002720 bpb` worse than the anchor. The stronger refutation came from the actual combo test itself, which finished at `1.412318`, and from the warmup-only branch, which collapsed to `1.419193`.

## Implications

The earlier low-confidence local hints for `WARMUP_RATIO=0.015` and `UNEMBEDDING_LR=0.005` should not be combined into a new default. The clearest actionable takeaway is that lowering warmup below `0.02` remains unstable under the current `FINAL_LR_FRAC=0.02` anchor. If future sessions revisit this area, they should treat `UNEMBEDDING_LR=0.005` only as a reproduction candidate under the existing warmup, not pair it with a lower warmup again without new evidence.
