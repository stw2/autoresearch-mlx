## Assertion

At the current depth-2, 128-d shallow anchor, the existing first-layer local attention window at 50% of sequence length remains the best tested setting. Making that first layer fully global was slightly worse, and shrinking the window to 25% or 12.5% of sequence length caused clear regressions without any compensating gain in step count or memory.

- Only the first-layer short-window fraction changed across non-control runs; peak memory stayed at `18.6 GB` and completed steps stayed in the `2211-2215` range

## Falsification

The explicit falsification run removed the local window entirely by setting `SHORT_WINDOW_FRAC=1.0`, which makes both layers effectively full-context at depth 2. If local attention in the first layer were actively hurting, this run should have beaten the anchor. Instead it regressed slightly to `1.432453`, and the more aggressive local-window runs at `0.25` and `0.125` were much worse, so the positive hypothesis failed.

## Implications

For the current shallow anchor, changing the first-layer attention span does not buy throughput and mostly just harms quality once the window gets smaller than the incumbent half-sequence setting. Follow-up work should treat the present windowing as provisionally stable and spend search budget on other training dynamics rather than pushing first-layer locality harder.
