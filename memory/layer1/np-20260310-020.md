## Assertion

Follow-up on the earlier warmup result shows that a small positive warmup still helps on the current shallow anchor, but the local optimum is lower than previously claimed. `WARMUP_RATIO=0.02` reached `val_bpb=1.413272`, beating the prior `0.05` anchor, while both zero warmup and a larger `0.1` warmup were worse.

## Falsification

The key falsification run removed warmup entirely (`WARMUP_RATIO=0.0`). If the earlier small-warmup win had been pure noise, the zero-warmup run should have matched or beaten the anchor; instead it regressed badly to `1.421969`. The follow-up neighbor at `0.1` also lost, while the old `0.05` setting failed to reproduce its earlier best, leaving `0.02` as the strongest point in this sweep.

## Implications

The earlier `0.05` nanopub should be treated as directionally right but numerically too high. Future schedule work should treat warmup as a narrow small-value knob around `0.02`, and the next useful follow-up is a reproduction or local sweep in the `0.01-0.03` range rather than revisiting zero or large warmups.
