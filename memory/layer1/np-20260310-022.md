## Falsification

The explicit disproof attempt removed the floor entirely (`FINAL_LR_FRAC=0.0`). If the previous `0.02` result had only been noise from a single run, the zero-floor variant should have matched or beaten it once retested from the same anchor. Instead it regressed sharply to `1.413529`, and both nearby probes at `0.01` and `0.03` also lost. The unresolved problem is not the local ordering but reproducibility: the control rerun at `0.02` finished `0.001937 bpb` behind the incoming anchor, so confidence in the absolute gain must remain low.

## Implications

Treat `FINAL_LR_FRAC=0.02` as the working local optimum for the current `WARMUP_RATIO=0.02` anchor, but not as a settled improvement over noise. The next useful follow-up is a reproduction-focused check such as repeated `0.02` versus `0.03` reruns, rather than a wider sweep away from this neighborhood.
